# Spec ID: 007 — 헌장 갱신: '강제' 정의 명시 + 2-tier 명명 + DEVIATION 정리

> 헌장 § 6.2 의 갱신 룰을 따르는 첫 사이클. 본 spec 은 헌장 본체(`docs/fde-criteria.md`) 의 정직성·일관성·적용성을 회복한다. F1-F5 자체는 변경하지 않는다 — *주변의 모호함만* 잡는다.

## What (무엇을)

`docs/fde-criteria.md` 의 4 가지 영역을 갱신한다:

1. **B9 해결** — § 5 의 "강제" 정의 명시 + 2-tier 명명 체계 도입 (FDE proper / FDE-inspired)
2. **DEVIATION 3건 정직화** — A1 (3-Actor 가 우리 transpose 임 명시) · A2 (weekly fallback 명시적 거부) · A3 (FAE 사촌론 약화)
3. **모호 4건 → § 7 미해결 이동** — B1 (관찰 증거 범위) · B2 (며칠 임계 수치) · B6 (양방향 빈도) · B8 (가치 측정 시점). 각각 "해결 시까지 보수적 적용" 가이드.
4. **내부 불일치 2건 수정** — C1 (부록 A 양식 보완) · C2 (회고 임계 수치 동기)

## Why (왜)

헌장(`docs/fde-criteria.md`) 이 PR #21 머지된 지 한 사이클 만에 self-evaluation 에 적용했을 때 **결과가 해석 의존** 으로 binding 력이 무력화됨 — B9 의 "강제" 정의 모호 때문. 또한 외부 사용자가 헌장을 읽었을 때 *원전 FDE* 와 *우리 해석* 을 구분 못 할 위험 (A1, A3).

빠르게 한 번 정리해야 다음 사이클부터 헌장이 실제로 작동한다. 본 spec 미진행 시 다음 모든 spec 의 self-check 가 *각자 다른 해석* 으로 통과·차단됨.

## Expected outcome (정량)

- 헌장 갱신 후 v0.2.0 재평가 시 *결과가 일관* — 해석 의존 ❌. 측정: 평가표 결과가 "강제 N 개" 의 N 이 명확히 결정됨
- 다음 사이클 spec 들이 부록 A 양식을 *모호함 없이* 사용 가능 — 측정: 부록 A 의 "깊은/얕은 진척" 분류가 spec reviewer 사이에 분쟁 없이 일치
- 외부 사용자가 README → 헌장 읽었을 때 "이건 우리 해석/이건 원전" 구분 가능 — 측정: § 1 첫 줄·§ 4 FAE 행에서 *원전 vs 변용* 표지가 즉시 식별됨

- [ ] § 5 에 "강제" 정의 명시 — *"강제 = F1-F5 각 § 2 의 '본 도구가 강제해야 하는 것' bullet 의 충족"*
- [ ] § 5 에 "깊은 진척" 정의 — *"해당 F# 의 모든 bullet 충족"*

  - **"FDE-inspired"** = 강제(얕은+깊은 합산) 2개 이상, 위 미달

### A 영역 — 정직화 (3건)

- [ ] § 4 FAE 행을 *"표면적으로 유사한 직무 패턴. *직접 계승 관계* 는 본 헌장이 주장하지 않음"* 으로 약화
- [ ] § 7 에 *"weekly fallback 은 FDE 가 아니다 — fde-harness 가 weekly 사용 패턴이면 § 5 의 F2 강제 인정 불가"* 명시 (A2 결정)

### B 영역 — 미해결로 이동 (4건)

- [ ] § 7 에 새 항목 4개 추가, 각각 *해결 시까지 보수적 적용* 가이드 포함:

  - **B2**: "F2 의 '며칠' 임계 수치 — 3일? 7일? 14일?" → *보수적 적용: 14일을 임시 한계로 가정, 데이터 누적 시 조정*

  - **B8**: "가치 측정 시점 — 즉시·1주·1개월" → *보수적 적용: 시점 자유, outcome.log 에 *측정 시점* 도 함께 기록*
